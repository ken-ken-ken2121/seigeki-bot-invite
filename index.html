DISCORD BOT ・ 声劇の進行役

進行bot をサーバーに招待する

声劇を始める前の準備（参加者集め、NG と上演時間の共有、台本の持ち寄りと投票、配役）を、チャンネルの中で順番に進めてくれる bot です。

サーバーに追加する

Discord が開くので、追加先のサーバーを選んで「認証」を押します。追加するには、そのサーバーの「サーバー管理」の権限が必要です。

https://discord.com/oauth2/authorize?client_id=1569860684794040454&scope=bot+applications.commands&permissions=274877991936

進行の流れ

  1. 参加者の募集ボタンで参加・取り消し。主催者が締め切ります
  2. 条件の設定参加者それぞれが NG と上演時間の上限を設定。上限は一番短い時間を使います
  3. 台本の提出チャンネルに台本の URL を貼るだけ。台本名はページから自動で読み取ります
  4. 投票本数と人数に合わせて1人1〜3票。全員の投票で決まります
  5. 役の入力主催者が役を入力。声劇台本置き場の登場人物欄はそのまま貼れます
  6. 希望役と配役重なった役は抽選。外れた人は残りの役から選び直せます
  7. まとめ台本名、URL、役表を投稿して終わります

追加するときに求められる権限

  • View Channels進行するチャンネルを見る
  • Send Messages案内やまとめを投稿する
  • Send Messages in Threadsスレッドの中でも進行する
  • Embed Links案内を見やすい枠で表示する
  • Read Message History貼られた台本の URL を読む

管理者権限やメンバーの管理などの強い権限は求めません。

追加したら

/声劇 開始そのチャンネルで進行を始めます。始めた人が主催者になります
/声劇 状況今どの段階かを確かめます
/声劇 中止主催者かサーバー管理者が進行を止めます

追加した直後は /声劇 が候補に出るまで少し時間がかかることがあります（最大1時間ほど）。

チャンネルごとに1つずつ進行できます。複数のチャンネルやサーバーで同時に使っても混ざりません。
